Design System

The package every product page loads through one link, design-system/index.css. Everything below is read from that package when the page opens, so a change made in design-system/ appears here on the next load.

Reading design-system/…

Package

The import tree, followed from index.css. Order is cascade order. patterns/, docs/ and examples/ are part of the package and appear here once something in them is imported.

Tokens

Every custom property in tokens.css, grouped by the section it is declared under. Primitive is a raw value; semantic points at one. Values are the browser's resolved values in the theme selected above. Ink tokens carry their contrast against --bg-page and --bg-surface, measured on this page (WCAG 1.4.3: 4.5:1 for body text, 3:1 for large text and UI).

Type

Every step the components may use, drawn from its semantic tokens (--type-{step}-size, -weight, -line, -track) in --font-ui. A component never writes a font value of its own. HIG · Typography: iOS's smallest default style is 11pt, and a step below it is marked.

Components

One file per component in components/, with the blocks each one declares. Specimens of every component in every state are in the UI kit.
