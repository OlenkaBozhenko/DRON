Shell

The frame every screen sits in, as markup — a two-layer header (status bar over nav bar) and a tab bar. A grayscale screen takes its shell from here; a CSS-only kit cannot dress what has no skeleton.

Two headers, one shell

Root screen — brand + title, no back. Pushed screen — a back button carrying the title of the screen you return to (‹ Order review), never “Back to…”. Per voice.md and HIG · Navigation bars, a tab-root screen has no back at all.
