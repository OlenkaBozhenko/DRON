A skeleton is a claim about the loaded screen, so it expires when that screen changes treatment.

The rule gives opposite answers by design. The question is never “should this pulse” but “does what loads replace this surface, or sit inside it”.

Only the arrow leaves the tray, because what the screen waits on is a file going up. It rests visible at 0% and 100%, so a dropped animation leaves a legible icon. 1.6s is the cadence of an upload, not of a spinner.
