The Tone-Step Rule. Separation between two surfaces is a warm tone step plus a radius, and the step is measured before it is used. A surface boundary is a decorative edge — not text (1.4.3), not a control or state indicator (1.4.11) — so no contrast minimum binds it.

HIG publishes no keyboard height and asks an app to read the keyboard's frame; 291 is what iOS measures in portrait on a 375 × 812 frame (216 keys + 45 QuickType + 30 home-indicator inset), and the accessory bar's 44 is the 44pt floor. Only the 216 is quoted — four rows divide it evenly at 45 with a 12 gutter. The plates above are scaled down to fit the page; the numbers are the build's, not the plate's.

Only Done is real. A multiline field's Return inserts a newline and cannot dismiss, which is why the pattern is an accessory bar rather than a Return key.

The action bar leaves while the keys are up — [hidden], not dimmed. Buttons drawn behind the plane while still in the tab order are a WCAG 2.4.11 Focus Not Obscured failure the moment focus reaches one; a tab root sheds its tab bar for the same reason. The exception is a composer living inside the bar, where the bar rides above the keys instead — hiding it would hide the field being typed into.

The field picks the plane. inputmode of numeric · decimal · tel or type of number · tel draws the pad; everything else draws QWERTY. Ten fields take the pad. The plane keeps its 291 either way — a keyboard's frame does not change with the layout inside it, so nothing downstream moves.

Mobile only. 291 is quoted from a phone in portrait; the tablet preset is an iPad and the desktop has a hardware keyboard, so the plane rises only while the viewport switcher says mobile, and switching away dismisses it.

The Skeleton-Measures-The-Load Rule. A loading block is the size of the thing it waits for: the order-history skeleton card is 263.0px against the delivered card's 263.6px; the delivery photo skeleton is 341 × 180 against a photo of 341 × 180. The arrow is pinned by the shrink order, not by a number. Label 0 0 auto, value 0 1 auto with min-width:0 and the ellipsis, chevron flex:none, row flex-wrap: nowrap. That last one is load-bearing and was measured: without it a 66-character value took the wrap instead of the ellipsis and the row went 44 → 78 with the chevron 325px in from the edge. After: both rows 44 × 341, the chevron flush with the row's trailing edge on a 14-character value and a 56-character one alike.

It replaced a control that opened nothing. On the built account-edit the row was a <span role="button"> announcing a menu it did not have (WCAG 4.1.2), marked with the text glyph ▾ — a character in the running font, not the 24-grid outline every other arrow here is drawn on. It is a real <button> now, so Enter, Space, the tab order and the accessible name come from the element.

The drawer is .dr-sheet, the surface share already carries; .dr-sheet--picker adds only the rise — translateY(100%) → 0 over --dur-sheet .32s, scrim fading with it, both animation:none under reduced motion. Measured open: sheet 373 wide, bottom flush with the frame, scrim 373 × 810 — over the nav bar and the action bar, not just the scroll area.

The modal contract is kept, not claimed. Everything behind goes inert — verified: #addr cannot take focus while the drawer is up. Focus lands on the current option with its ring, Tab cycles inside the drawer only, and it closes three ways — Esc, the scrim, and Cancel (HIG · Action sheets asks for the cancel by name; the × belongs to a full modal sheet screen, not to a drawer) — each returning focus to the row, which by then says the new value.
